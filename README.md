# HireLens 聘镜 — 招聘端第一眼视角的本地全链路 AI 求职系统

> **设计初衷**：招聘官每天浏览数百条打招呼消息与推荐卡片时，未点开列表往往**仅外露前 15~18 个汉字**，人才推荐流卡片默认**仅折叠展示前 2 行（约 52 字）并高亮搜索命中词**。**HireLens（聘镜）** 从招聘端真实屏幕显示机制倒推求职策略，打通「多平台采集 → 双层排雷 → 重点前置文案与一页定制简历渲染 → 飞书双向协同 → 拟人安全投递 → 全景转化统计 → 多轮模拟面试」的本地隐私优先闭环。

---

## ✨ 核心架构与特性

### 1. 👀 招聘端第一眼实时模拟台（Recruiter Lens）
- **HR 手机未点开消息列表模拟**：实时计算打招呼语前 17 字截断区，直观对比「普通寒暄撞脸沉底」与「硬实力钩子前置」的屏幕反差。
- **推荐牛人卡片流模拟**：针对 140 字「个人优势」实时呈现两行折叠边界与 HR 搜索关键词标红高亮计数。
- **点开会话首屏阅读压力检测**：监控聊天气泡行数，避免大段长文造成阅读负担。

### 2. 🔌 通用 BYOK 多厂商大模型网关（支持免 Key 本地离线）
- 网页端顶部一键切换 **13+ 主流服务商预设**：DeepSeek、硅基流动、阿里云百炼（通义千问）、月之暗面 Kimi、智谱 GLM、火山方舟、OpenAI、Anthropic Claude（原生协议）、Google Gemini、OpenRouter，以及免 API Key 的本地 **Ollama / LM Studio**。
- 内置 URL 自动规范化、`<think>` 推理链剥离、`/models` 模型列表自动拉取与首响延迟实测；未配置任何云端 Key 时可零成本运行本地启发式规则引擎。

### 3. 🛡️ 双向物理 PII 隐私脱敏与本地隔离
- 默认绑定 `127.0.0.1` 本地回环并支持可选访问口令门禁。
- 所有发往外部大模型的简历与 JD 均先通过 `PIIMasker` 将姓名、手机号（含内地/香港）、邮箱、微信号、院校、敏感机构与个人域名物理替换为占位符，返回后在本地内存还原。

### 4. ⚡ 多源极速采集与双层排雷漏斗
- **四种录入通道**：BOSS直聘 / 猎聘 / 前程无忧(51job) / 智联招聘低频安全巡航 + **macOS 原生 Apple Vision 离线零成本截图识岗（`Cmd+V` 即粘即识）** + 杂乱网页文本一键拆解 + Chrome Manifest V3 剪藏扩展。
- **双漏斗排雷**：Tier-1 本地毫秒级硬词与沉睡 HR 拦截 + Tier-2 语义侦察（识别隐形驻场外派、薪资跨度虚标、低底薪对赌与骗试稿）。

### 5. 🖨️ 严守事实边界的定制简历渲染 & 四平台投递
- 基于多赛道核验母本注入靶向匹配摘要（拒绝全文胡编指标），静默生成 **一页净版 A4 PDF 简历** 与 **高清图片简历**。
- 内置四平台在线简历结构化映射助手（带基础联系方式只读防覆写锁）与拟人安全投递引擎（遇平台验证码立即安全挂起，绝不强闯）。

### 6. 💬 飞书零手工建表双向协同 & 📈 全景数据统计大盘
- **一键自动建表（Auto-Schema）**：填入个人飞书自建应用凭证即可自动创建标准多维表格与下拉选项列，支持手机端修改审批状态与备注后反向同步回本地 SQLite，并配备 ChatOps 机器人指令与富文本战报卡片。
- **全景统计大盘**：7 阶求职转化漏斗、14 日趋势图、多渠道 ROI 矩阵、4 赛道对比及按动作拆解的 Token 成本审计台账。

## 🚀 快速开始

```bash
# 1. 启动服务（自动创建虚拟环境并监听 http://127.0.0.1:8765）
./run.sh

# 2. 运行自动化单元与集成测试套件
.venv/bin/python3 -m unittest discover -s tests -v
```

启动后打开浏览器访问 **http://127.0.0.1:8765**，点击右上角 **`🔌 LLM`** 按钮即可接入你自己的大模型 API 或使用本地离线模式。个性化简历母本与隐私词表可放入本地 `data/local_resumes/` 与 `data/candidate_profile.json`（已被 `.gitignore` 严格保护，不会上传至代码仓库）。
